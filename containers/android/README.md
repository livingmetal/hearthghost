# Reproducible Android builder

The HG-013 Android toolchain is built from pinned container and Google command
line tool digests. It installs only Android platform 36 and the explicitly
required build-tools 35.0.0 and 36.0.0,
then runs web checks/tests/build, Capacitor sync, Android unit tests, lint, and a
debug APK build as the non-root `android-builder` user.

```text
podman build -f containers/android/Containerfile \
  -t localhost/hearthghost-android-build:local .
podman run --rm --network none \
  localhost/hearthghost-android-build:local
```

The resulting debug APK is
`/workspace/android/app/build/outputs/apk/debug/app-debug.apk` inside the image.
Debug app signing is generated by the Android build and is unrelated to the
Android Keystore Node identity. No signing key, Node key, certificate, provider
credential, build cache, or APK is copied into the repository or image inputs.
